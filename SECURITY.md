# Security Policy

## Supported Versions

We release security patches for the following versions of FocalDOM:

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |
| < 0.1.0 | :x:                |

## Reporting a Vulnerability

We take the security of **FocalDOM** and our users seriously. If you believe you have found a security vulnerability in any package or application within this monorepo, please report it responsibly:

### How to Report
1. **DO NOT** create a public GitHub issue for security vulnerabilities.
2. Email your vulnerability report to `dhaatrikchowdhury@gmail.com` with the subject prefix `[SECURITY] FocalDOM Vulnerability`.
3. Include the following details in your report:
   - Type of vulnerability and affected package(s) (`@focaldom/core`, `@focaldom/capture-playwright`, etc.)
   - Step-by-step instructions or proof-of-concept to reproduce the issue
   - Potential impact of the vulnerability
   - Any suggested mitigations or patches

### Response Timeline
- **Initial Acknowledgment:** Within 48 hours of receipt.
- **Vulnerability Assessment:** Within 5 business days.
- **Fix & Disclosure:** We will coordinate a patched release and public disclosure timeline with you.

Thank you for helping keep FocalDOM safe and secure!
